# ShopFlow roadmap

## Milestone 0 — prototype
- [x] Responsive dashboard shell
- [x] Product creation
- [x] Manual order entry
- [x] Customer summary
- [x] Printable invoice
- [x] Local browser persistence

## Milestone 1 — customer validation
- [ ] Interview 5 independent sellers
- [ ] Observe how they currently record orders
- [ ] Confirm the most painful repetitive task
- [ ] Test willingness to pay before adding paid infrastructure

## Milestone 2 — production foundation
- [ ] Choose supported hosting and database regions
- [ ] Add authentication
- [ ] Enforce store-level row access
- [ ] Add migrations, backups, and error monitoring
- [ ] Add privacy policy and terms

## Milestone 3 — sellable product
- [ ] Public store page
- [ ] Customer order form
- [ ] Inventory and low-stock alerts
- [ ] CSV export
- [ ] Branded invoice PDF
- [ ] Billing only after payment-provider eligibility is verified
